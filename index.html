    Settings

    Drug data sources

    Where ingredient and dosing data comes from. Free sources work out of the box. Paid or registered ones connect below.

    Indian brand list

    Lookups use 0 brands. Import more as a CSV with brand,composition columns, or the Kaggle "A-Z Medicine Dataset of India" file as-is. Imports last for this session only.

    openFDA key

    Free from open.fda.gov. Raises the limit from 1,000 to 120,000 requests a day.

    Connect a provider (ABDM Drug Registry, DrugSetu, DrugBank…)

    Each provider has its own format, so point this at a small adapter on your server that calls the provider with your key and returns {"matched","ingredients":[{"name","strength_mg"}]}. Use {name} where the medicine name goes. Tried before the US database.
